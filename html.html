核心實績：以數據推動自動化與系統整合

透過傾聽搜集全貌、透過全局思考釐清脈絡，並透過扎實的技術實作搭起解決問題的橋樑：

智慧製造設備異常預警與自動化報表系統

  • 異質系統無縫編排：以 n8n 為核心，整合 PostgreSQL、Google Gemini AI、Discord 及 SMTP 服務。
  • 嵌入式 GenAI 分析：將 AI 直接嵌入自動化流程。偵測異常時，即時請求 AI 進行根因分析並提供建議。
  • 智慧動態報表：透過 IF Node 區分熱數據與存檔冷數據；結合 SQL 聚合查詢與 JS，實現全自動 HTML 每日報表。

FitRoute AI 自行車運動智能助手

  • 架構設計與整合：負責系統架構設計，補足了 React/Flask 前後端整合的實務經驗。
  • 大規模數據清洗：串接 Google Maps API 與 Strava 數據，運用 Pandas 處理超過 15 萬筆數據，確保訓練品質。
  • 模型整合應用：整合 XGBoost 演算法與輕量化模型 Gemma 3-4B，成功實作功率預估與個人化騎乘建議功能。

警力機動性空間評分模型 (PostGIS)

  • 空間資料庫建置：建立 PostgreSQL/PostGIS 空間資料庫，運用 Spatial SQL 取代傳統人工疊圖。
  • 演算法導入：導入 KNN (K-Nearest Neighbors) 演算法計算最佳路徑。
  • 全自動化分析：突破傳統桌面軟體 (Desktop GIS) 限制，實現具備數據支撐且全自動化的警力可及性評分模型。

都市三維建築形態對鳥類碰撞風險分析

  • 突破二維限制：利用高解析度的 Global Building Atlas (GBA) 三維建築資料，精確量化都市垂直結構的阻礙。
  • 空間關聯性探討：分析不同建築形態（高度、體積、密度）與候鳥、留鳥碰撞風險之關聯性。
  • ESG 生態指標：研究成果為都市友善環境設計與 ESG 評估標準提供具體的科學依據。
